# Student Registration System

A responsive Student Registration System developed using PHP, MySQL, HTML, CSS, and Bootstrap.

## Features

* Student Registration
* Student Login
* Dashboard
* Edit Profile
* Logout System
* Session Management
* Responsive UI

## Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* Bootstrap
* XAMPP

## Project Modules

### Authentication Module

Users can register and login securely.

### Dashboard Module

Displays student details after successful login.

### Profile Management

Users can update their profile information.
